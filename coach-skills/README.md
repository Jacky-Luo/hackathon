# Coach Skills

This folder stores the distilled coach models used by the daily review demo.

- `steve-jobs-perspective`: focus, product simplification, first-version scope.
- `zhang-yiming-perspective`: structured governance, owner, metric, feedback loop.
- `wang-jinxin-perspective`: business path review, falsification, mechanism closure.
- `wjx-2-perspective`: three-gate review model: real problem, evidence, failure signal.
- `cai-jun-perspective`: multi-guest social product and growth judgment.
- `trump-perspective`: weekly narrative, resources, leverage, negotiation framing.
- `naval-perspective`: assetization, compounding leverage, reusable systems.

The `minutes/` folder in the repository contains the meeting transcripts that supplied the real weekly context for the demo.
